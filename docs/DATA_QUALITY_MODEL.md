# VillageCoverage V3 데이터 품질 평가 모델 (§18)

## 1. 개요 및 설계 원칙

VillageCoverage V3에서는 단일 숫자로 축약된 모호한 신뢰도 점수(예: 73/100) 대신, **7가지 명시적 품질 차원(Dimensions)**과 **규칙 기반 종합 상태(Overall Status)**를 제공합니다.

- **가짜 정밀도 배제**: 인위적인 점수 계산 대신 `양호(GOOD)`, `제한적(LIMITED)`, `미흡(POOR)`, `확인 불가(UNKNOWN)`의 4단계 불연속 분류를 적용합니다.
- **결정론적 판정**: 동일한 관측 이력과 메타데이터에 대해 항상 동일한 품질 평가 결과를 산출합니다.
- **출처 투명성(Provenance)**: 보정 미완료(`UNCALIBRATED`)는 계획 수립을 무조건 차단하는 결함이 아니라, 공공데이터 기반 기본 추정치를 사용함을 알리는 출처 경고(Provenance Warning)로 취급합니다.

---

## 2. 7가지 품질 차원 (Dimensions)

| 차원 (Dimension) | 한국어 명칭 | 기준 | 등급 판정 규칙 |
| :--- | :--- | :--- | :--- |
| **OBSERVATION_COVERAGE** | 관측량 | 유효한 수요 관측 건수 | • `>= 6건`: GOOD (양호)<br>• `2~5건`: LIMITED (제한적)<br>• `1건`: POOR (미흡)<br>• `0건`: UNKNOWN (확인 불가) |
| **RECENCY** | 최신성 | 최신 근거 자료 수집 후 경과일 | • `<= 90일`: GOOD (양호)<br>• `91~180일`: LIMITED (제한적, 노후화 진행)<br>• `> 180일`: POOR (미흡, 만료)<br>• 자료 없음: UNKNOWN |
| **SOURCE_DIVERSITY** | 출처 다양성 | 서로 다른 수요 증빙 채널 수 (전화, 마을총회, 대리신청, 현장실사 등) | • `>= 3개`: GOOD (양호)<br>• `2개`: LIMITED (제한적)<br>• `1개`: POOR (미흡)<br>• `0개`: UNKNOWN |
| **SURVEY_COMPLETENESS** | 조사 완성도 | 심층 설문 조사 및 필수 항목 기재 여부 | • 설문 완료 및 현장확인 불필요: GOOD<br>• 설문 완료했으나 보완 필요: LIMITED<br>• 현장 조사 필요(`needs_survey=True`): POOR<br>• 설문 미실시: UNKNOWN |
| **CONFLICT_STATUS** | 충돌 상태 | 동일 권역 내 상충되는 수요 증빙 존재 여부 | • 충돌 0건 (또는 검토 완료): GOOD<br>• 경미한 차이 1건 (검토 중): LIMITED<br>• 미해결 충돌 `>= 2건`: POOR |
| **DUPLICATE_REVIEW_STATUS** | 중복 검토 | 동일 수요의 중복 등록 검토 상태 | • 중복 0건 (또는 검토 완료): GOOD<br>• 잠재 중복 1~2건: LIMITED<br>• 미해결 중복 `>= 3건`: POOR |
| **CALIBRATION_STATUS** | 보정 상태 | 관측치 기반 통계적 수요 계수 보정 여부 | • 계수 보정 완료(`CALIBRATED`): GOOD<br>• 잠정/부분 보정(`PROVISIONAL`): LIMITED<br>• 미보정(`UNCALIBRATED`): LIMITED (관측치 2건 이상) / POOR |

## 3. 종합 품질 상태 (Overall Status)

각 권역의 7개 차원 평가 결과를 바탕으로 계획 수립 가부를 3단계로 명확히 판정합니다:

### 1) 충분 (`SUFFICIENT`)
- **판정 기준**: 관측량 GOOD, 최신성 GOOD/LIMITED, 충돌/중복 미흡 없음, 조사 완성도 GOOD.
- **의미**: 정규 일정 최적화에 완전한 신뢰도로 투입 가능합니다.
- **UI 표기**: `충분 (정상 계획 가능)`

### 2) 제한적 (`LIMITED`)
- **판정 기준**: 최신성이 노후화 진행 중(91~180일)이거나, 관측량이 2~5건이거나, 경미한 충돌/중복 검토가 진행 중인 경우.
- **의미**: 계획 수립은 가능하나, 배정 우선순위나 출처 경고(Provenance Warning)가 함께 표기됩니다.
- **UI 표기**: `제한적 계획 가능`

### 3) 현장 조사 필요 (`SURVEY_REQUIRED`)
- **판정 기준**: 관측량이 1건 이하이거나, 최신 근거가 180일을 초과(만료)했거나, 심각한 미해결 수요 충돌이 있거나, `needs_survey=True`인 경우.
- **의미**: 자동 알고리즘의 임의 추정 배정을 금지하며, 현장 실사나 전화 확인을 통한 사실 확인을 우선 배정합니다.
- **UI 표기**: `현장 조사 필요`

## 4. UI 노출 가이드라인 (Village Detail)

권역(마을) 상세 화면에서는 다음과 같은 직관적인 표 형태로 사용자에게 안내합니다:

```text
[데이터 상태]
- 관측량:       제한적 (3건)
- 최신성:       양호 (42일 전)
- 출처 다양성:  양호 (전화, 마을총회)
- 충돌:         검토 완료 (0건)
- 보정 상태:    미보정 (기본 계수 적용)

[종합 평가]
제한적 계획 가능 (최신성 및 일부 데이터 보완 권장)
```
