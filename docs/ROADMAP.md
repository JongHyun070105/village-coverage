# Roadmap after V5.2 RC1

다음 단계는 기능 확장보다 현장 검증과 운영 근거 확보입니다. 각 단계는 기관 승인과 자료 사용 근거를 먼저 확인합니다.

1. **실제 pilot partner 확보** — 담당자·권역·서비스 범위·책임자와 검토 절차를 합의합니다.
2. **기관 승인 dataset 확보** — 목적·법적 근거·최소 수집·접근·보존·삭제 조건을 문서화합니다.
3. **공급자 운영 검증** — 디렉터리 등재와 실제 서비스, 가용성, 용량, 가격, 참여 의사를 별도 확인합니다.
4. **현장 execution data 수집** — 계획·수행·취소·불참·미충족을 동의된 방식으로 연결합니다.
5. **현장 보정과 예측 평가** — 충분한 종단 관측이 확보된 뒤 대표성·오차·불확실성·편향을 사전 정의한 방식으로 검토합니다.
6. **인증·권한 설계** — 별도 보안·개인정보 검토를 거친 뒤 기관 identity, role, 접근 기록과 보존 정책을 설계합니다.

공모전 제출자료나 실제 pilot partner 탐색은 다음 product 단계로 다룹니다. RC 범위에 새 서비스, AI model, provider source, 결제·SMS·GPS 또는 production auth를 추가하지 않습니다.
