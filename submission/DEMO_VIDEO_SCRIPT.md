## 촬영 규칙

- 로그인, 설치, CSV 대기 화면은 생략한다. 실행 직후 핵심 화면으로 컷한다.
- 촬영 전 데이터 리셋과 같은 조건의 시나리오 재실행 방법을 기록한다. 화면 수치가 `artifacts/experiment_results.json`과 다르면 2:10–2:38 내레이션의 숫자는 사용하지 않는다.
- 화면에서 해당 비교를 정확히 재현하지 못하면 수치 narration을 넣지 않는다. 통제 실험의 정확한 숫자는 보고서와 claim map에서 제시한다. 영상 자막을 위해 제품 화면과 다른 실험 그래픽을 만들어 넣지 않는다.
- PII, 이메일·전화번호, API 키, 브라우저 저장소, 개인별 연락처를 화면·자막·음성에 담지 않는다.
- 승인·제공자 참여는 모두 DEMO 역할·시뮬레이션이라고 보인다. `실증 완료`, `실제 효과`, `실제 공급자 가격` 표현을 쓰지 않는다.
- 영상 해상도·화면비는 공고에 `NOT_SPECIFIED`. 화면은 읽히는 데스크톱 캡처를 우선하고, 별도 권고 해상도를 공식 요구로 표현하지 않는다.
