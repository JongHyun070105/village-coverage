# VillageCoverage 테스트 안내

## 접속 상태

- 테스트 URL: `PLACEHOLDER — 안전한 공개 데모 미구현, 현재 제공 불가`
- 제출 기준: 웹 서비스 테스트 URL이 공식 필수 항목이다. 현재 로컬 서비스는 제출 URL을 대신하지 않는다.
- 테스트 자료: 데모·합성 데이터. 실제 주민, 실제 공급자 운영상태·가격, 현장 결과가 아니다.

URL을 발급하기 전에는 외부 평가자에게 이 저장소의 로컬 또는 임시 배포 주소를 보내지 않는다. 현재 앱에는 인증/인가가 없고 주민 연락처 조회와 상태 변경 경로가 있어 공개 인터넷 배포는 안전하지 않다. 세부사항은 [`DEPLOYMENT_PLAN.md`](DEPLOYMENT_PLAN.md)를 본다.

## URL이 안전하게 준비된 뒤 권장 순서

1. Dashboard에서 대상 지역, 공개자료 기준일, `DEMO DATA` 배지를 확인한다.
2. 자료가 적은 마을의 상세 화면에서 관측 수, 근거 품질, `조사 필요` 상태를 확인한다.
3. Scenario Compare에서 같은 예산의 효율·균형·소외 최소화·최소보장 결과와 solver 상태를 비교한다.
4. DEMO 제공자의 참여 상태를 변경하고 재계획 전후의 비용·권역·미충족 결과를 비교한다. 이는 실제 업체 통보나 공급 확정이 아니다.
5. Decision Memo에서 정책 선택, 근거, 미배정 사유가 기록되는지 본다. 화면의 역할 선택은 인증이나 법적 결재가 아니다.
6. Evidence Center에서 `REAL PUBLIC`, `EXTERNAL PRIOR`, `SIMULATED`, `UNKNOWN` 표시를 확인한다.

## 읽기 범위와 주의사항

- 수치·예산·지역 선택은 시연용 합성 조건일 수 있다. 모든 숫자의 데이터 배지를 확인한다.
- “최소보장”은 모든 요청량이나 주민 결과를 보장하지 않는다. 설정한 최소 서비스 기회를 충족하는 권역 수를 우선 비교한다.
- 시연 전에 synthetic-only 데이터 적재와 reset/session isolation이 확인되어야 한다. 그런 보장이 갖춰지기 전에는 공개 URL을 발급하거나 쓰기 기능을 평가자에게 안내하지 않는다.
- 실제 주민 이름, 연락처, 상세 사례, 제공자 개인 연락처를 입력하지 않는다. 연락처 기능은 공개 데모에서 차단되어야 한다.
- 지역 서비스 실제 운영, 실제 가격, 예측 정확도, 현장 효과를 검증하는 도구가 아니다.
