목표 길이: 약 4분 35초 (공고 허용 2–5분)<br>
상태: `VIDEO_NOT_RENDERED`<br>
주 촬영 원칙: 실제 브라우저 제품 화면만 녹화하고, 합성 실험 카드는 원본 실험 artifact에서 별도 카드로 보여준다.

## 촬영 전 통과 조건

- 공개 URL과 API를 새 브라우저 세션에서 확인하고 Dashboard 데이터 오류가 없어야 한다.
- Scenario Compare에서 4개 정책 비교, Plans에서 불참 반영 재계획 및 PDF/CSV 다운로드를 새 세션에서 확인한다.
- 영상으로 보여줄 화면은 `공개 데모 · 합성/공개 데이터` 및 시뮬레이션/모델 추정 고지를 함께 남긴다.
- 2026-10-13 원격 브라우저 확인은 UI는 열렸지만 데이터 재조회가 두 번 실패했다. 이 게이트가 해소될 때까지 원격 UI 촬영은 보류한다.
- 현재 포함된 캡처는 격리된 로컬 Playwright E2E의 합성 데이터 화면이며, Render 배포 화면이 아니다.

## 촬영 시작 상태와 실제 클릭 순서

1. 새 브라우저 프로필에서 공개 URL을 열고, 본문·API 상태가 정상인지 확인한다. 첫 로드와 데이터 재조회 실패가 있으면 촬영을 중단한다.
2. Dashboard 공개/합성 데이터 안내 → 근거·출처 → Scenario Compare 순으로 이동한다.
3. Scenario Compare에서 `지역=홍성군 장곡면`, `월 예산=5000000` → `4안 비교 실행`을 누른다.
4. 계산 완료 뒤 네 정책 카드, 미충족·조사 필요, 제약 설명을 읽는다. 필요한 분석 표는 버튼을 하나씩 실행하고 완료 상태를 확인한다.
5. 합성 회차의 `데모 불참`을 선택 → `계획 승인·이력` → `불참 1건 반영해 새 버전` → `계획 v2` 확인.
6. 검토자료 PDF, 계획 요약 PDF, 회차 CSV를 내려받고 각 파일이 열리는지 확인한다.
7. 별도 실험 카드(아래 승인된 수치만)를 보여준 뒤 한계와 사람 검토 원칙을 말하고 끝낸다.

## 영상에서 사용할 수 있는 검증 수치

아래는 모두 `artifacts/experiment_results.json#experiment_1_request_count_vs_balanced` 한 건에서만 인용한다. 파일 SHA-256은 `4d984db66fc9b90624dbbb1a26245b6e7f52b3b89e77e44a381c05dfb2cf24eb`이다.

- 홍성군 장곡면 공개 집계·고정 도로행렬과 합성 수요/관측/공급/가격, 16개 권역, 예산 5,000,000원, seed 2026.
- 요청량 기준안과 균형안: 각 19개 서비스 단위, 배정 3/16 대 12/16, 미배정 13 대 4, 합성 조사 필요 권역 배정 0/8 대 7/8.
- 모델 이동비는 각각 612,525원과 432,899원이며 실제 집행비 또는 절감액이 아니다.
- 이 두 정책 결과를 UI의 네 정책 E2E 결과와 합치지 않고, 다른 정책에 일반화하지 않는다.

## 자막 / 내레이션 일치 감사

- `AI가 농촌 수요를 정확히 예측`, `실제 9개 마을 추가 지원`, `비용을 절감했다`, `모든 요청을 충족했다` 금지.
- 생성형 AI는 구성된 Gemini 구조화 출력 경로와 결정적 fallback이 코드에 있다. 공개 배포에서 실제 모델 호출이 실행되었다고 말하지 않는다.
- 시나리오 계산은 CP-SAT 역할로 말하고, AI가 직접 예산을 배분한다고 말하지 않는다.
- 공급자 불참과 검토/승인 상태는 시연 데이터다. 법적 결재·계약·서비스 완료라고 부르지 않는다.
- 실제 촬영 전 모든 화면과 문장을 재검수하고, 촬영 후 2–5분 길이 및 다운로드 결과를 확인한다.

## 현재 클릭 경로 검증 범위

통과한 Playwright 시나리오는 `공급자 불참` 상태를 API로 설정한 뒤 브라우저에서 새 계획 버전과 산출물을 확인했다. 화면에서 사람이 `데모 불참`을 눌러 저장하는 경로는 아직 이 E2E가 직접 검증하지 않았다. 촬영 리허설에서 그 버튼의 상태 변경과 계획 재계산을 확인하고, 버튼이 없거나 결과가 다르면 촬영을 중단한다.
