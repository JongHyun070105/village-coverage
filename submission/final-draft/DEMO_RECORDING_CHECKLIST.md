# VillageCoverage 데모 영상 촬영 체크리스트

목표 길이: 4분 30초 전후. 공식 허용 범위: 2-5분.

## 녹화 전 통과 조건

- [ ] 공개 테스트 URL과 API가 HTTPS로 열리고, 새 브라우저 세션에서 계획 데이터가 표시된다.
- [ ] 현재 2026-10-13 원격 확인에서는 웹 UI 뒤 데이터 재조회가 실패했다. 재촬영 전 원격 API/브라우저 흐름을 새 세션에서 다시 확인한다.
- [ ] 공개 데모 안내의 합성/공개 데이터, 세션 격리, 모델 추정 고지가 화면에 남아 있다.
- [ ] 같은 5,000,000원 조건으로 효율·균형·소외 최소화·최소보장 4개 결과가 계산된다.
- [ ] 제공자 참여 페이지에서 `데모 불참`이 현재 세션의 합성 회차에만 적용되고, 계획 v2가 생성된다.
- [ ] 계획 상세에서 미배정 사유와 Decision Memo를 확인하고 PDF/CSV를 내려받을 수 있다.
- [ ] 비정형 기록 구조화는 공개 데모에서 접근이 제한될 수 있다. 생성형 AI 결과를 녹화한다면 설정된 모델 호출임을 확인하고, 실제 생성이 없으면 AI가 실행된 것처럼 말하지 않는다.

조건이 실패하면 촬영을 중단한다. 실제 원격 화면 대신 가짜 UI·재구성 화면·역사적인 캡처를 현재 시연처럼 편집하지 않는다. 이 문서의 로컬 E2E 캡처는 제품 코드 검증 자료이며 원격 Render 시연이 아니다.

2026-10-13 확인 결과: 격리 로컬 E2E는 1건 통과해 네 정책 비교·불참 후 재계획·PDF/CSV 내보내기를 검증했다. 다만 테스트는 제공자 불참을 브라우저 화면 버튼이 아니라 API 상태 변경으로 입력했다. 따라서 영상에서 사람이 `데모 불참` 버튼을 누르는 실제 화면 경로는 아직 별도 확인이 필요하다. 원격 URL은 데이터 재조회 오류가 재현되어 위 체크박스를 통과한 것으로 표시하지 않는다.

## 브라우저 시작 상태와 클릭 순서

1. 시크릿/새 브라우저 세션에서 `https://villagecoverage-public-demo-web.onrender.com/`을 연다. 로그인·실명 데이터는 쓰지 않는다.
2. 대시보드의 `공개 데모 · 합성/공개 데이터` 배너와 `실제 주민·공급자 운영정보나 행정 승인을 포함하지 않습니다` 문구가 보이는지 확인한다.
3. 상단 `시나리오 비교`로 이동한다. 지역과 월 예산 5,000,000원을 확인하고 `4안 비교 실행`을 누른다.
4. 최소보장 분석, `비교 계산`, `2순위·3순위 후보 계산`, `예비 정책 비교`는 요청이 완료된 뒤 각 결과 표가 표시될 때만 촬영한다. 화면의 비용은 모델 추정치로 읽는다.
5. `공급자 참여`에서 합성 회차에만 `데모 불참`을 선택한 뒤 `계획 승인·이력`에서 `불참 반영해 새 버전`을 실행한다. 계획 버전이 1에서 2로 바뀌었는지 확인한다.
6. 계획 v2의 미배정 권역·사유를 보여주고 `검토보고서 PDF`, `계획 요약 PDF`, `회차 CSV`를 내려받는다. 검토 요청/승인은 데모 상태로만 설명한다.
7. `근거·출처` 또는 `데이터 출처`에서 공개자료·외부 참고·합성 운영값 구분을 보여주며 마무리한다.

## 촬영 품질과 개인정보

- 녹화 크기/비율은 공고에서 지정하지 않았다. 읽히는 데스크톱 화면과 16:9 편집을 내부 선택으로 사용한다.
- 브라우저 알림·주소 자동완성·다운로드 경로·탭·계정 이름·개발자 콘솔·환경변수는 화면에서 제외한다.
- 실제 주민 기록, 이름, 연락처, 이메일, API 키, 쿠키, 브라우저 저장소는 입력하거나 녹화하지 않는다.
- 수치 화면은 `SIMULATED FOR PRE-R&D` 또는 제품의 `SIMULATION` 배지를 같이 보인다.
- 같은 `experiment_results.json` 수치와 네 정책의 실제 화면 결과를 한 시나리오인 것처럼 합치지 않는다.
- 음성은 대본을 읽되 화면 상태와 맞지 않는 문장은 잘라낸다. 최종 길이는 2-5분을 넘지 않는지 확인한다.

## 보관 산출물

- 원본 녹화/편집 프로젝트는 공개 저장소 밖에 둔다.
- 제출 전 영상 전체에서 개인정보·실제 서비스 주장·화면과 내레이션 불일치를 사람이 검수한다.
- 현재 상태: `VIDEO_NOT_RENDERED`.
