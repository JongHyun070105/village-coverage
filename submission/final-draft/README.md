# 제출 초안 패키지 안내

## 먼저 볼 파일

- 최종 제출용 형식 후보는 `VillageCoverage_성과보고서_20261023.pptx`다. 공식 4장 PPT 양식 기반이다.
- `VillageCoverage_성과보고서_20261023.docx`는 동일한 주장을 담은 공식 Word 양식 기반 대안이며 2쪽 이내를 목표로 한다. Office 렌더 후 페이지 수를 확인해야 한다.
- 파일명에 `검증미리보기`가 들어간 PDF 2개는 이 작성 환경에서 만든 QA 전용 미리보기다. PowerPoint/Word 변환 결과가 아니므로 제출용 PDF로 쓰지 않는다.
- 공식 빈 신청서 사본과 작성 안내는 `VillageCoverage_참가신청서_작성대기.docx`, `.hwp`, `APPLICATION_FILL_GUIDE.md`다. 개인정보/동의/서명은 없다.

## 증거와 영상

- `CLAIM_VERIFICATION.md`: 주장별 구현 근거, artifact hash, 전제, 한계, 제출 안전 표현.
- `evidence/CAPTURE_MANIFEST.md`: PPT에 넣은 실제 로컬 E2E 캡처의 출처 및 적용 한계.
- `DEMO_FINAL_SCRIPT.md`, `DEMO_RECORDING_CHECKLIST.md`, `JUDGE_DEMO_GUIDE.md`: 영상 제작 대본과 재현 지침. 실제 영상은 아직 없다.
- `FINAL_PACKAGE_STATUS.md`: 공식 요건, 현재 검증 상태 및 제출 전 사용자 확인 목록.

## 반드시 남은 확인

아이디어 번호/가점/수상 상태, 참가자 정보·동의·서명, IP 관계를 참가자가 확인해야 한다. 공개 Render URL은 2026-10-13 데이터 요청 오류가 재현되어 촬영/제출 가능한 상태로 확인되지 않았다. 실제 Office에서 PPTX/DOCX를 열어 native PDF 변환·쪽수·한글 글꼴·잘림을 확인하고, 정상 원격 데모로 2–5분 영상을 별도 촬영해야 한다.

이 저장소 패키지에는 실제 개인 참가정보, 서명, 비공개 영상 파일을 넣지 않는다.
